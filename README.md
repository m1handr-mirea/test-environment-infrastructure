# Стенд автоматического развертывания тестовых сред

Для запуска нужны Python 3.11+, включённый Docker Engine с Compose v2
и терминал macOS или Linux. В Docker Desktop используется локальный контекст.
Команды выполняются из папки стенда. Для первой сборки нужен доступ
к Docker Hub и PyPI.

```bash
python3 envctl.py up feature-a
python3 envctl.py up feature-b
python3 envctl.py status feature-a
python3 envctl.py logs feature-a
python3 envctl.py check feature-a
```

Команда `up` выводит адрес после прохождения проверок. Откройте оба адреса
в браузере и сохраните метку в одной среде. Во второй среде поле останется
пустым. Порт назначает Docker. Для повторного открытия адрес можно получить
командой `check`. Имя среды должно быть уникальным среди пользователей
одного Docker Engine и содержать от 1 до 30 строчных латинских букв,
цифр и дефисов. Первый символ — буква или цифра.

```bash
python3 -u verify.py
python3 envctl.py down feature-a
python3 envctl.py down feature-b
```

`verify.py` создаёт две временные среды с уникальными именами, проверяет
их и удаляет созданные ресурсы. `down` удаляет том с данными выбранной среды.
Адреса доступны на машине с Docker. Среды используют тестовые данные.
Для запуска CI поместите содержимое этой папки в корень GitHub-репозитория.
Задание использует временную машину GitHub Actions и выполняет тот же тест.
